Shopify E-Commerce Business Report

Project Overview:
This is a live sales performance dashboard built using Shopify data, Google Sheets, and Looker Studio.

Tools Used:
- Data Source: Shopify (via Google Sheets)
- Visualization: Google Looker Studio
- Data Cleaning: Google Sheets

Dashboard Includes:
1.  Total Sales (Scorecard): Total number of orders
2.  Sales by Country (Geo Map): Visual distribution of orders

Key Insights (Oct 2026):
- Total Orders: 5
- Top Performing Country: United States (100%)
- Report Status: Live & Automated
